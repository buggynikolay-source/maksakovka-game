# Скриншоты автора

Пять изображений, приложенных к сообщению с отзывом о первой сборке. Автор отметил отделённые от дверей ручки, плоскую картинку/темноту у выхода из подъезда и то, что для встречи с Костей пришлось вручную выбрать сцену. Пять файлов — оригинальные изображения, только переименованные, чтобы избежать одинаковых имён `image.png`. Перед публикацией проверяйте наличие личных данных на скриншотах.
