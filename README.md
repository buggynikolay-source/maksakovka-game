# Игра про Верхнюю Максаковку — пакет переноса

Снимок существующего браузерного прототипа пролога «Спиннер», v0.1. Финальное название игры не утверждено. Это не полная игра и не полный пролог: доступные сцены — квартира, подъезд и двор. Код в `vm/` скопирован без изменений.

Для игры откройте `vm/dist/maksakovka_prologue_v0.1.html` двойным щелчком в Chrome, Edge или другом современном браузере с WebGL. В сборку уже встроен Three.js; интернет для игры не нужен. Управление: WASD и мышь, Shift — бег, E — действие/следующая реплика, 1–3 — выбор, F — спиннер, Esc — пауза.

**Переносимость:** исходный `vm/build.js` использует абсолютный путь `/data/vm`; тестовый `vm/test.js` тоже привязан к старому окружению. Их не меняли. Инструкции и последствия — в [run.md](docs/run.md).

`feedback/` содержит пять скриншотов пользователя с замечаниями к превью, `vm/shots/` — технические скриншоты, сделанные при разработке. Это материалы для отладки, а не ассеты игры. Перед публикацией в открытый репозиторий проверьте приватность и права на материалы; лицензию проекта автор пока не определил. Файлы Three.js содержат указание MIT; см. [architecture.md](docs/architecture.md).

`SHA256SUMS.txt` содержит контрольные суммы всех остальных файлов этого пакета. Репозиторий GitHub не создавался; история Git в исходной папке не обнаружена.
