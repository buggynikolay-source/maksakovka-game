# GitHub и Hoplite: первоначальная настройка

## Рекомендуемое имя репозитория

`maksakovka-game`

Название репозитория техническое и не фиксирует финальное название игры.

## Создание репозитория

1. На GitHub нажмите **New repository**.
2. Введите `maksakovka-game`.
3. Выберите **Private** на время проверки содержимого.
4. При создании не добавляйте второй README, `.gitignore` или лицензию: они уже подготовлены или намеренно не выбраны в этом пакете.
5. Создайте пустой репозиторий.

## Загрузка файлов

Распакуйте архив `maksakovka-github-ready-v0.1.zip`. Загружайте **содержимое корневой папки архива**, чтобы в корне GitHub-репозитория находились `README.md`, `AGENTS.md`, `.gitignore`, `docs/`, `feedback/` и `vm/`.

Если используете Git в PowerShell:

```powershell
git clone https://github.com/ВАШ_ЛОГИН/maksakovka-game.git
cd maksakovka-game
# Скопируйте сюда содержимое распакованного архива
git add .
git commit -m "Import Maksakovka prototype v0.1"
git push
```

Замените `ВАШ_ЛОГИН` на свой логин GitHub. Команды предполагают, что Git установлен и авторизация GitHub уже настроена.

## Подключение к Hoplite

1. В Hoplite подключите GitHub-аккаунт.
2. В установке GitHub App разрешите доступ только к `maksakovka-game` (вариант **Only select repositories**).
3. Вернитесь в Hoplite, обновите список репозиториев и выберите `maksakovka-game`.
4. После создания проекта попросите агента сначала только прочитать `AGENTS.md`, `README.md`, `docs/status.md` и `docs/architecture.md`.
5. Не поручайте агенту сразу исправлять всё. Сначала получите отчёт о понимании проекта и план минимальных изменений.

## Первый запрос агенту

> Прочитай `AGENTS.md`, `README.md`, `docs/status.md`, `docs/architecture.md`, `docs/run.md`, `docs/design-document.md` и `docs/prologue-script.md`. Ничего не изменяй. Сверь описание с исходниками в `vm/src/` и готовой сборкой в `vm/dist/`. Кратко перечисли: что реально реализовано, какие ошибки уже отмечены автором, какие ограничения мешают сборке и тестированию на новой машине. Предложи безопасный план следующих шагов, но не выполняй его до моего подтверждения.

Лицензия игры ещё не выбрана. Не добавляйте `MIT` или другую лицензию к собственному коду без решения автора. Пока держите репозиторий приватным. В `vm/` есть сторонняя библиотека Three.js с MIT-уведомлением; перед публичной публикацией сохраните требуемые copyright и license notices.
